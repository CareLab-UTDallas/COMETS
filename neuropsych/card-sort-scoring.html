Score a card-sorting protocol

Each row is one response by an invented examinee. Mark which dimensions the response card shares with the key card it was placed under, whether the sort was correct, and whether it was perseverative. Then total the protocol and check your scoring. Cards are written out in words, so no test materials appear here.

Nothing here is saved. Practice as often as you like, and generate new sequences when the four cases feel familiar.
The rules this tool scores by
  1. The correct category starts as color and changes after 10 consecutive correct responses, in the order color, form, number, color, form, number. The test ends after six categories.
  2. Before the first category is complete, the first unambiguous error sets the perseverated-to principle and is not itself perseverative. Later unambiguous errors to that principle are perseverative, even with other responses between them.
  3. After each completed category, the category just completed becomes the perseverated-to principle.
  4. Three unambiguous errors to a principle that is neither correct nor perseverative, with every response from the first to the third matching that principle, make it the new perseverated-to principle. Scoring starts with the second of the three.
  5. An ambiguous response that includes the perseverated-to principle is perseverative only when the nearest unambiguous responses before and after it are both perseverative to that principle and every response between them matches it. It can be perseverative and still correct.
  6. A failure to maintain set is an error after 5 or more consecutive correct responses, before the category is complete.

This tool follows the rules as taught on the Canvas page. Some scoring handouts state rules 2 and 4 differently or add a separate failure-to-maintain-set rule for children. Score by the rules above. Learning to learn is not scored here.

Conceptual level responses are correct responses in runs of three or more, and a run continues across a category change when the next response is also correct. If no category was completed, trials to complete the first category is 65, the 64 cards of the deck plus one. Score each practice sequence as if it were the whole test.
